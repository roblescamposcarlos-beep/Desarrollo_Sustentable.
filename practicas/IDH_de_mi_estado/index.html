¿Qué es el IDH?

El Índice de Desarrollo Humano, creado por el Programa de las Naciones Unidas para el Desarrollo (PNUD), resume en un valor de 0 a 1 tres capacidades básicas de las personas. Entre más cerca de 1, mayor es el nivel de desarrollo humano.
