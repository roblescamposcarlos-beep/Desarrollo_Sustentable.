¿Qué es el Índice de Desarrollo Humano?

El IDH, elaborado por el Programa de las Naciones Unidas para el Desarrollo (PNUD), resume en un valor de 0 a 1 tres capacidades básicas de las personas. Mientras más cerca de 1, mayor es el nivel de desarrollo humano.
