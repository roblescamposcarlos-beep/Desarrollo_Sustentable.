# Desarrollo Sustentable

Sitio web informativo sobre la diferencia entre "sostenible" y "sustentable"
y el impacto ambiental del almacenamiento en la nube, con un formulario de
opinión conectado a una automatización en Make (Google Sheets + correo de
agradecimiento). Ver [Documentacion/MAKE_SETUP.md](Documentacion/MAKE_SETUP.md)
para el detalle de la automatización.
